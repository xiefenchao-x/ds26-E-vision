# MaixCAM 侧算法总结提示词

下面这段可以直接发给队友，让他据此写报告中的“视觉识别与拼图求解算法”部分。

```text
请根据以下内容，整理一段适合电赛报告的 MaixCAM 端视觉算法说明。要求语言正式、结构清晰，可以分为“总体流程、A4 定位、碎片检测、第一题求解、第二题求解、多帧稳定与输出协议”几个小节。不要写成代码说明书，而要写成报告里的算法原理和实现流程。

项目背景：
本项目使用 MaixCAM2 作为视觉端，摄像头采集 A4 纸工作区图像，在板端通过 OpenCV 完成 A4 定位、透视矫正、拼图碎片识别、目标位姿求解，并通过 UART 将每块拼图的抓取点、放置点和旋转角发送给 STM32/执行机构。当前 MaixCAM 入口文件为 maixcam/main.py。

一、总体算法流程：
1. MaixCAM 摄像头采集 640x480 BGR 图像。
2. 检测图像中的 A4 纸外框，得到四个角点，按左上、右上、右下、左下排序。
3. 根据 A4 四角点建立透视变换，将实际纸面映射到标准平面坐标 WARP_W x WARP_H，即 594x420 像素，对应 A4 的 29.7cm x 21.0cm。
4. 在 A4 内部区域建立检测 mask，去掉纸张边框附近干扰。
5. 对拼图碎片进行颜色/亮度分割、轮廓提取、多边形近似、面积和形状过滤，得到每块碎片的中心、外接框、顶点数和多边形轮廓。
6. 根据题目模式选择不同求解策略：
   - 第一题：已知 10cm x 6cm 矩形及固定切割模板，进行模板匹配和目标位姿计算。
   - 第二题：未知拼接关系，基于边长匹配和几何评分搜索碎片拼接方式。
7. 按键触发采样，连续采集多帧，剔除异常帧并对角点、碎片中心、轮廓和角度做平均，提升稳定性。
8. 将标准 A4 坐标转换为机械坐标，生成移动任务包，通过 UART 发送。

二、A4 纸定位算法：
A4 检测采用传统图像处理流程，不依赖深度学习。
处理步骤为：
1. 将原图灰度化。
2. 使用 5x5 高斯滤波降低噪声。
3. 使用 Canny 边缘检测，当前阈值为 50 和 150。
4. 对边缘图做形态学闭运算，连接断裂边缘。
5. 查找所有轮廓，对轮廓面积进行筛选，保留面积占整帧 7% 到 65% 的候选。
6. 对轮廓使用 Douglas-Peucker 多边形近似，要求近似结果为四边形且为凸多边形。
7. 对四边形进行几何校验：
   - 长宽比需要落在 1.25 到 1.65 之间，接近 A4 纸比例；
   - 四个内角需要在 65 到 115 度之间；
   - 使用相对面积过滤，避免将中线分割出的半张纸误判为 A4。
8. 在候选中选择面积最大的四边形作为 A4 外框。
9. 若某一帧检测失败，稳定器会保留最近一次有效结果最多 5 帧，减少画面抖动。

A4 检测成功后，通过 cv2.getPerspectiveTransform 建立原图四角点到标准 A4 平面的单应矩阵，同时得到逆矩阵。标准平面中 A4 中线为 x = WARP_W / 2，用于区分左右区域和规划目标侧。

三、碎片检测算法：
碎片检测只在 A4 内部区域进行。首先根据 A4 四角点生成内缩 mask，再裁剪 ROI 以减少计算量。

当前默认使用 black 模式分割碎片，适合黑色背景或暗色纸面上检测较亮碎片：
1. 将 ROI 转换到 HSV 空间。
2. 取 V 通道作为亮度图。
3. 对亮度图进行 3x3 高斯平滑。
4. 在 A4 内部 mask 中取亮度的 20 分位数估计背景亮度 bg_v。
5. 阈值取 max(90, bg_v + 55)，亮度高于阈值的区域判定为碎片。
6. 通过中值滤波平滑二值 mask，并限制在 A4 内部区域内。

代码中还保留了 HSV 绿色背景差分和 Lab 背景色差两种分割方式：
- HSV 模式通过计算像素到绿色背景阈值范围外的距离来生成 mask；
- Lab 模式估计背景 Lab 中位颜色，再计算加权色差。

得到 mask 后进行轮廓提取，并按以下条件过滤：
1. 面积占标准 A4 平面比例需要在 0.2% 到 30% 之间。
2. 外接框宽高不能太小，且长宽比不能超过 8。
3. 轮廓不能贴近图像边界，避免误识别 A4 边框或残留噪声。
4. 使用多边形近似简化轮廓，碎片顶点数限制为 3 到 5 个。
5. 通过合并短边减少圆角和噪声造成的多余顶点。
6. 第一题模式下可进一步用直线拟合修正角点，提高几何精度。

每个碎片最终记录的信息包括：
- id：碎片编号；
- center：标准 A4 坐标系中的质心；
- bbox：外接矩形；
- polygon：碎片多边形顶点；
- expanded_polygon：按中心外扩后的轮廓，用于目标预览和位姿计算；
- side：碎片位于 A4 左半区或右半区；
- area、points：面积和顶点数量。

四、第一题算法：
第一题使用已知模板匹配。题目中的完整矩形尺寸为 10cm x 6cm，程序中预先定义四个模板 A、B、C、D，每个模板用厘米坐标下的多边形表示。

第一题核心步骤：
1. 对检测到的碎片轮廓和四个模板轮廓做归一化：平移到中心、按最大半径缩放到固定尺度。
2. 使用 OpenCV matchShapes 计算碎片与各模板的形状相似度。
3. 计算碎片面积占总碎片面积的比例，并与模板理论面积比例比较。
4. 同时考虑形状分数、面积比例分数和顶点数差异，遍历模板排列组合，选择总代价最小的匹配结果。
5. 根据碎片当前所在半区自动选择目标拼装区：如果碎片平均 x 坐标在右半区，则目标放在左半区；否则目标放在右半区。
6. 将 10cm x 6cm 模板按需要旋转为竖向 6cm x 10cm，并映射到标准 A4 坐标。
7. 计算每块碎片从当前姿态到目标模板姿态的旋转角：
   - 对 A/B/C 这类非对称碎片，优先使用主轴方向估计旋转；
   - 若主轴不可用，则通过边界重采样和边方向候选搜索估计旋转；
   - 对 180 度歧义，通过边界距离和特征角方向评分选择正确方向。
8. 输出每块碎片的抓取中心、目标放置中心和旋转角。

五、第二题算法：
第二题不再依赖固定 A/B/C/D 模板，而是根据碎片几何关系自动搜索拼接方案。当前默认求解模式为 branched_spine，并保留 common、t_junction、corner、concave、equal_rectangles 等多种参考拓扑模式。

第二题核心思想是“边匹配 + 位姿图装配 + 几何评分”：
1. 对每块碎片提取所有边，同时允许把连续近似共线的小边合成为复合边，以提高对复杂切割边的适应能力。
2. 对不同碎片之间的边两两比较：
   - 若两条边长度相近，相对误差小于约 12%，生成完整边匹配候选；
   - 若一条边可能只对应另一条边的一部分，则生成局部边匹配候选，并记录对应的参数区间。
3. 对候选边匹配进行组合搜索，保证：
   - 每条边或边区间不能被重复使用；
   - 所有碎片在匹配图中连通；
   - 不同切割拓扑下使用不同数量和类型的匹配边组合。
4. 对每一组匹配，构建位姿图：
   - 固定第 0 块碎片为参考坐标；
   - 根据匹配边的端点建立刚体变换，使两块碎片的匹配边反向贴合；
   - 沿图传播得到所有碎片的旋转和平移；
   - 若图中存在闭环，累计闭环误差。
5. 对装配结果进行几何评分，选择分数最低的方案。评分项包括：
   - 匹配边误差；
   - 闭环误差；
   - 碎片重叠面积；
   - 拼接外接矩形填充率；
   - 与目标矩形面积、长宽比、周长的偏差；
   - 凸包空洞；
   - 外边界是否接近矩形边；
   - 边界覆盖是否完整；
   - 未匹配边是否能补齐矩形边界；
   - 边接触距离；
   - 直角点与矩形四角的对应误差。
6. 对闭环匹配较多的情况，使用简化的最小二乘位姿图优化，进一步降低匹配边残差。
7. 将最优拼接结果归一化，使整体矩形竖向摆放，并缩放到 A4 左/右半区可用空间内。
8. 为每块碎片生成目标多边形、目标中心和旋转角，形成 move_plan。

第二题算法的优点是不用事先知道每块碎片属于哪个模板，只依赖边长、边界、矩形完整性等几何约束完成搜索。缺点是对轮廓顶点提取质量较敏感，因此前面的分割和多边形近似精度很关键。

六、多帧采样与稳定策略：
为了避免单帧误识别，程序不是每帧都发送结果，而是按键触发一次采样流程：
1. 按键后连续采集 60 帧。
2. 每帧完成 A4 检测和碎片检测。
3. 首先剔除 A4 角点偏离中位值过大的帧。
4. 第一题按模板名分组，第二题按碎片数量和中心位置分组。
5. 对碎片中心、轮廓顶点、面积和旋转角进行异常值过滤和平均。
6. 至少需要 2 帧有效样本才认为采样成功。
7. 采样成功后保持结果显示约 65 秒，并只发送一次串口任务包。

这一策略能显著减小摄像头噪声、边缘抖动和瞬时光照变化对最终机械动作的影响。

七、坐标转换与串口输出：
视觉内部使用标准 A4 坐标，单位为像素。程序通过四点标定矩阵将标准 A4 坐标转换到机械坐标：
- 标准 A4 平面四角为 (0,0)、(WARP_W-1,0)、(WARP_W-1,WARP_H-1)、(0,WARP_H-1)；
- 机械标定点默认为 A4 实际毫米坐标，可根据实车修改；
- 当前为了适配 STM32 坐标系，输出前会交换 X/Y。

每块碎片最终输出：
- ID；
- PICK_X、PICK_Y：抓取点；
- PLACE_X、PLACE_Y：目标放置点；
- ROTATE_X10：旋转角乘以 10，单位为 0.1 度。

默认串口格式为二进制包：
AA 55 LEN PAYLOAD CHECKSUM
PAYLOAD = COUNT + COUNT 个 11 字节记录
单条记录格式为：
ID(uint8), PICK_X(int16), PICK_Y(int16), PLACE_X(int16), PLACE_Y(int16), ROTATE_X10(int16)
校验和为 LEN 与 PAYLOAD 所有字节之和的低 8 位。

八、报告中可以强调的创新点/工程特点：
1. 使用 A4 纸透视矫正建立统一物理坐标系，使像素坐标和厘米/毫米坐标可直接换算。
2. 采用传统 OpenCV 算法，计算量小，适合 MaixCAM2 板端实时运行。
3. 碎片识别支持多种颜色空间分割方式，并针对现场黑色背景优化了动态亮度阈值。
4. 多边形近似、短边合并和角点直线拟合提高了碎片几何描述稳定性。
5. 第一题利用模板形状、面积比例和顶点数联合匹配，避免只靠单一特征导致误判。
6. 第二题采用边匹配候选搜索和几何评分函数，在未知切割方式下自动恢复拼接位姿。
7. 多帧采样、异常值剔除和平均融合提升了最终发送给机械端的可靠性。
8. 输出协议简洁固定，便于 STM32 端解析和执行。
```
